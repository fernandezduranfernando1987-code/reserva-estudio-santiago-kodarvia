1. Crear/Mover/Cancelar sin recargar
2. Anti-solape con haySolape()
3. Validación campos obligatorios
4. localStorage key: kodarvia_reservas
5. Mobile first
6. Panel admin clave: admin123 (const CLAVE en App.tsx)
7. Carga <3s
8. Este README
